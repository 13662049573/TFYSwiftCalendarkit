# Security Policy

## Supported versions

Security fixes are provided for the latest minor release. Applications should pin at least a minor version and review changelog entries before updating.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `420144542@qq.com`. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real user calendar data, event titles, account identifiers, or credentials.

TFYSwiftCalendarkit does not transmit data and has no runtime network dependency. EventKit access exists only in the example application; host applications remain responsible for permission messaging and data handling.
